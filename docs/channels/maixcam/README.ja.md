# MaixCam

MaixCam は、Sipeed MaixCAM および MaixCAM2 AI カメラデバイスへの接続専用チャンネルです。TCP ソケットを使用した双方向通信を実装し、エッジ AI デプロイメントシナリオをサポートします。

## 設定

```json
{
  "channel_list": {
    "maixcam": {
      "enabled": true,
      "type": "maixcam",
      "host": "0.0.0.0",
      "port": 18790,
      "allow_from": []
    }
  }
}
```

| フィールド | 型     | 必須   | 説明                                                          |
| ---------- | ------ | ------ | ------------------------------------------------------------- |
| enabled    | bool   | はい   | MaixCam チャンネルを有効にするかどうか                        |
| host       | string | はい   | TCP サーバーのリッスンアドレス                                |
| port       | int    | はい   | TCP サーバーのリッスンポート（デフォルトは `18790` で、Gateway の HTTP ポートと同じです。同じホストで両方を動かす場合は別のポートを設定してください）                                  |
| allow_from | array  | いいえ | 許可するデバイスIDのリスト。空の場合は誰でも許可されます（Gateway が警告をログに出力します）。設定するか、全員を意図的に許可する場合は `["*"]` を使用してください |

## ユースケース

MaixCam チャンネルにより、NeuroClaw はエッジデバイスの AI バックエンドとして機能できます：

- **スマート監視**：MaixCAM が画像フレームを送信し、NeuroClaw がビジョンモデルで分析する
- **IoT 制御**：デバイスがセンサーデータを送信し、NeuroClaw がレスポンスを調整する
- **オフライン AI**：ローカルネットワークに NeuroClaw をデプロイして低遅延推論を実現する
